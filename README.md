## 🔥 Git Commit Convention 
| 커밋 타입 | 설명 |
|-----------|------------------------------------------------|
| 🎉 `feat` | 새로운 기능 추가 |
| 🐛 `fix` | 버그 및 오류 수정 |
| 📝 `docs` | 문서 수정 (README 등) |
| 📝 `style` | 문서 수정 (README 등) |
| 🔄 `REFACTOR` | 코드 리팩토링 (기능 변경 없음) |
| 🔄 `test` | 코드 리팩토링 (기능 변경 없음) |
| 🛠 `chore` | 코드 수정, 내부 파일 수정 |
| 📝 `comment` | 문서 수정 (README 등) |
| 📝 `rename` | 문서 수정 (README 등) |
| 📝 `remove` | 문서 수정 (README 등) |
| 📝 `init` | 문서 수정 (README 등) |
| 🧪 `TEST` | 테스트 코드 추가 및 수정 |
